# DEVIL PLAYS 🎧
**Your Music. Your World. Your Vibe.**

A complete, production-ready Native Android Offline Music Player built with **Kotlin**, **Jetpack Compose**, **AndroidX Media3 (`ExoPlayer` + `MediaSessionService`)**, **`MediaStore`**, and hardware **AudioFX (`Equalizer`, `BassBoost`, `Virtualizer`)**.

## Quick Build Instructions (Android Studio)
1. Extract this ZIP archive.
2. Open **Android Studio** -> **Open** -> Select the `DevilPlays` folder.
3. Wait for Gradle Sync to finish.
4. Click **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
5. Your signed, installable APK will be generated at:
   `app/build/outputs/apk/debug/app-debug.apk` (or `app/build/outputs/apk/release/app-release.apk` when running `assembleRelease`).
